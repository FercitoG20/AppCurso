📦 ¿QUÉ ES UN ARRAY?

Un Array es una variable especial que funciona como una "lista" o una "caja con compartimentos".

La creamos usando corchetes [ ].

let lista_canciones = ['Pop', 'Rock', 'Clásica', 'Reggae'];

🔢 EL ÍNDICE (LA CLAVE)

Para seleccionar un elemento de la lista, usamos su índice (su posición).

¡MUY IMPORTANTE! En programación, las listas empiezan a contar desde CERO (0).

[ 'Pop', 'Rock', 'Clásica', 'Reggae' ]

   0          1           2             3     

🎸 ¿CÓMO PEDIMOS 'ROCK'?

Viendo la lista, 'Rock' está en la posición número 1.

Para obtener 'Pop' -> lista_canciones[0]

Para obtener 'Rock' -> lista_canciones[1]

Para obtener 'Clásica' -> lista_canciones[2]

✅ TU MISIÓN

Usa el comando tocar_cancion() y pásale la canción 'Rock' usando su índice.

// El juego ya te da la 'lista_canciones'

tocar_cancion(lista_canciones[1]);

¡No escribas "Rock"! ¡Usa el índice!
