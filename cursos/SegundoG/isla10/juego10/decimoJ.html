📜 EL PROBLEMA

No sabemos las palabras, solo las runas: 'alpha' y 'beta'.

Necesitamos "traducirlas":

  • 'alpha' ➔ 'LUX'
  • 'beta' ➔ 'NOVA'

✨ EL 'RETURN' (DEVOLVER)

Crearemos una función que, en lugar de *hacer* algo, nos *devuelve* un valor.

Usamos la palabra clave return para "entregar" un resultado.

PASO 1: DEFINIR LA FUNCIÓN

Esta función *recibe* una runa (parámetro) y *devuelve* la palabra correcta (return).

function traducir_runa(runa) {
  if (runa == 'alpha') {
    return 'LUX';
  }
  if (runa == 'beta') {
    return 'NOVA';
  }
}

PASO 2: CAPTURAR EL VALOR

¡Ahora usamos nuestra función para *obtener* el valor y *guardarlo* en una variable con let!

let palabra1 = traducir_runa('alpha');
let palabra2 = traducir_runa('beta');

¡Ahora palabra1 vale 'LUX' y palabra2 vale 'NOVA'!

✅ TU MISIÓN COMPLETA

2. Crea las variables palabra1 y palabra2 llamando a tu función.

3. Llama a activar_portal(palabra1, palabra2).
