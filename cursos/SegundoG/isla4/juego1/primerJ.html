📦 ¿QUÉ ES UNA VARIABLE?

Una variable es como una caja con un nombre donde podemos guardar datos (como números o texto).

Para crear una "caja" (variable), usamos la palabra clave let.

let mi_caja;

// Esto crea una variable vacía llamada 'mi_caja'

ASSIGNAR UN VALOR (=)

Para guardar un dato en nuestra "caja", usamos el signo = (se llama operador de asignación).

let mi_caja;
mi_caja = 100;

// Ahora, la variable 'mi_caja' CONTIENE el número 100

✨ EL MÉTODO RÁPIDO ✨

¡Podemos crear y asignar en una sola línea! Esto se llama "inicializar".

let mi_caja = 100;

¡Es la forma más común de hacerlo!
