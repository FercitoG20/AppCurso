📦 PASO 1: "AGARRAR" EL ELEMENTO

Nuestra página (el "DOM") es como un cofre. Para usar un elemento (como el cristal), primero debemos "agarrarlo" por su ID.

let cristal = document.getElementById('cristal_magico');

🎧 PASO 2: "ESCUCHAR" EL EVENTO

Ahora que tenemos el cristal, le decimos que "escuche" un evento. El evento más común es el 'click'.

cristal.addEventListener('click', ... );

⚙️ PASO 3: LA "FUNCIÓN CALLBACK"

Le pasamos una "receta" (una función) para decirle qué hacer CUANDO ocurra el clic. Esto se llama "callback".

cristal.addEventListener('click', function() {
  // El código aquí dentro...
  // ...solo se ejecuta AL HACER CLIC
});
