📦 ¿QUÉ ES UNA FUNCIÓN?

Una Función es una "receta" mágica que guarda una secuencia de comandos para usarlos más tarde.

¡Es la forma de crear tus propios comandos!

PASO 1: DEFINIR LA FUNCIÓN

Primero, *creamos* la receta con la palabra clave function. Elige un nombre para tu hechizo.

// 1. Pones los comandos que quieres guardar DENTRO de { ... }

function hechizo_luz() {
  activar_runa();
  lanzar_energia();
}

PASO 2: LLAMAR A LA FUNCIÓN

¡Crear la receta no hace nada! Debes *usarla* (llamarla) escribiendo su nombre con paréntesis ().

// Esto le dice al programa: "¡Ejecuta la receta 'hechizo_luz' AHORA!"

hechizo_luz();

✅ TU MISIÓN COMPLETA

Escribe esto en tu editor:

// 1. Definir el hechizo

function hechizo_luz() {
  activar_runa();
  lanzar_energia();
}

// 2. Llamar al hechizo

hechizo_luz();
