🎯 OBJETIVO

Escribe un código que decida si abrir_cofre() o ignorar_cofre().

El problema: ¡Algunos cofres tienen trampas!

📖 LA VARIABLE

Para ayudarte, te daremos una variable. Una variable es como una caja que guarda un dato.

Nuestra variable se llama tipo_cofre.

tipo_cofre = 'tesoro' (¡Genial!)
tipo_cofre = 'trampa' (¡Peligro!)

❓ EL COMANDO "IF" (SI...)

Usamos if para hacer una pregunta.

El == (doble igual) se usa para comparar.

// Esto se lee como: "¿La variable tipo_cofre CONTIENE 'tesoro'?"

if (tipo_cofre == 'tesoro') {
  // ...código a ejecutar SÍ la respuesta es SÍ
}

🤷 EL COMANDO "ELSE" (SI NO...)

else se ejecuta si la pregunta del if fue NO.

if (tipo_cofre == 'tesoro') {
  abrir_cofre();
} else {
  // Esto se ejecuta si el cofre NO era 'tesoro'
  ignorar_cofre();
}

¡Este es el código que necesitas!
