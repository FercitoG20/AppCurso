📦 EL MALETÍN (OBJETO)

Los datos están en este "maletín" digital. En programación, esto es un Objeto.

Un Objeto es una variable que guarda *otras variables* dentro de ella, usando "llaves" y "valores".

LLAVE : VALOR

Los objetos se ven así:

let maletin = {
  usuario: 'Agente001',
  password: 987,
  activo: true
};

⚙️ LA NOTACIÓN DE PUNTO (.)

Para *leer* un valor de un objeto, usamos un punto (`.`) y el nombre de la "llave" (la propiedad).

maletin.usuario

// Esto nos da el valor 'Agente001'

maletin.password

// Esto nos da el valor 987
