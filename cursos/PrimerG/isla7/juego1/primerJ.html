¡Debemos escanear 3 Golems: 'golem_tierra', 'golem_fuego' y 'golem_hielo'!

El comando base del taller es escanear_componente(nombre).

💡 ¡ABSTRACCIÓN!

En lugar de llamar a escanear_componente() 3 veces, ¡creemos nuestro propio comando (función) para simplificar!

Pero esta vez, la función debe ser *flexible*.

📦 ¿QUÉ ES UN PARÁMETRO?

Un Parámetro es una variable especial que pones en los paréntesis ( ) al *definir* tu función.

Actúa como una "caja" vacía, esperando recibir un dato.

function escanear_golem( objetivo ) {
  // 'objetivo' es el parámetro
}

⚙️ USAR EL PARÁMETRO

Dentro de tu función, puedes *usar* esa "caja" (el parámetro) como cualquier otra variable.

function escanear_golem( objetivo ) {
  escanear_componente( objetivo );
}

¡Ahora tu función escanear_golem es un atajo para el comando escanear_componente!

📞 LLAMAR CON UN ARGUMENTO

Al *llamar* a tu función, le pasas el dato que quieres que llene la "caja" (el parámetro). Este dato se llama argumento.

// 'golem_tierra' es el argumento

// Dentro de la función, 'objetivo' se convertirá en 'golem_tierra'

escanear_golem( 'golem_tierra' );

✅ TU MISIÓN COMPLETA

1. Define la función escanear_golem(objetivo).

2. Llama a tu función 3 veces, una para cada golem.

function escanear_golem(objetivo) {
  escanear_componente(objetivo);
}

escanear_golem('golem_tierra');
escanear_golem('golem_fuego');
escanear_golem('golem_hielo');
