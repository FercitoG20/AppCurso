📦 LA LISTA DE TAREAS

El robot recibe sus órdenes en un Array:

let lista_de_tareas = ['limpiar', 'regar', 'cocinar', 'ordenar'];

📏 LA PROPIEDAD '.length'

¿Cómo sabe el bucle cuántas veces repetirse? ¡Preguntándole a la lista!

Usamos .length para saber el tamaño de un array.

lista_de_tareas.length

// ¡Esto nos da el número 4!

⚙️ EL BUCLE AUTOMÁTICO

Ahora usamos .length en nuestro bucle for. ¡Así funcionará con cualquier número de tareas!

for (let i = 0; i < lista_de_tareas.length; i++) {
  // ...código a repetir...
}

🔗 LA COMBINACIÓN FINAL

Dentro del bucle, usamos la variable i (que valdrá 0, 1, 2, 3) para acceder a cada tarea.

for (let i = 0; i < lista_de_tareas.length; i++) {
  let tarea_actual = lista_de_tareas[i];
  hacer_tarea(tarea_actual);
}

✅ TU MISIÓN

1. Escribe el bucle for usando lista_de_tareas.length.

2. Dentro del bucle, obtén la tarea actual usando lista_de_tareas[i].

3. Llama a hacer_tarea() con esa tarea.
